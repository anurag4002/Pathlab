The reference header, watermark, marketing footer and corner are extracted
from the lab report supplied for this project. They contain no patient results,
registration barcode, QR code or signature artwork. Signatures are rendered
only from the corresponding report's stored sign-off records.

These assets are the default when a document format enables reference
branding and the lab profile has no replacement image. Turn reference
branding off to use editable lab identity text instead. Uploading an image
through Lab Profile replaces the corresponding header, watermark/logo or
footer. Assets are bundled with the serverless function via vercel.json.
